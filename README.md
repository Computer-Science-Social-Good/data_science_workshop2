# Data Science Workshop 2: Machine Learning Deep Dive

A beginner-friendly machine learning workshop hosted by **CS+Social Good at the University of Delaware**.

Building on our first workshop, we'll explore more machine learning algorithms, learn how to evaluate models, and apply them to a real-world dataset.

## Workshop Overview

We'll use the **Titanic dataset from Kaggle** to predict whether a passenger survived based on information like their age, ticket class, and fare.

Topics covered:
- Review of the data science pipeline and basic ML algorithms
- Logistic Regression
- Random Forests
- Model evaluation (accuracy, precision, recall, confusion matrices)
- Overfitting and cross-validation
